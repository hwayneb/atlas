# Legacy Runtime ADRs

This folder contains early Atlas Architecture Decision Records from the offline-first D&D engine phase.

These ADRs remain useful for implementation history and runtime traceability, especially for the local-first runtime, event store, world state, and AI adapter foundation.

They are not the Architecture v1.0 ADR index.

Architecture v1.0 decisions live in:

```text
docs/ARCHITECTURE-DECISION-RECORDS/
```

The authoritative decision index is:

```text
DECISION-LOG.md
```
