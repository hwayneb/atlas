# Atlas Roadmap

Build the Campaign Runtime foundation in small, reviewable slices.

## Completed Foundation Work

- MVP-001: Local-first web/PWA shell and sample campaign
- FEAT-003A: Command Processor
- FEAT-003B: Append-only Event Store

- FEAT-004: Projection Manager first slice
